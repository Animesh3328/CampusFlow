# CampusFlow Submission Checklist

- [x] Source code organized into Java packages
- [x] Maven `pom.xml`
- [x] Java 17 compiler release configuration
- [x] JUnit tests
- [x] README.md
- [x] statement.md
- [x] System architecture documentation
- [x] Use case, workflow, component, class, sequence and ER diagrams
- [x] Screenshots directory
- [x] Final project report PDF
- [x] Build verification record
- [x] Git-ready `.gitignore`

## Before final upload

1. Fill in student name, registration number and faculty/mentor in the report cover page if required.
2. If the course portal asks for a GitHub URL, create/push the repository from the CampusFlow folder.
3. Do not upload local H2 database files or generated logs unless specifically requested.
4. Keep the final report PDF and source ZIP together as the submission record.
