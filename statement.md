# Project Statement

## Problem Statement

Campus facilities such as classrooms, laboratories, seminar spaces and equipment are shared by students, faculty members and departments. Manual or fragmented booking processes can make availability difficult to track, create conflicting reservations and make usage records harder to maintain.

CampusFlow addresses this problem through a Java-based management system that combines resource discovery, conflict-aware booking, event registration, notifications and reporting in one application.

## Scope

The project focuses on campus resources and events. It supports role-based users, resource CRUD operations, bookings, booking cancellation, event management, event registration, notifications, reports, file export, runtime diagnostics and local database persistence.

## Target Users

- Students
- Faculty members
- Campus administrators

## High-Level Features

- User registration and authentication
- Role-based menus
- Resource CRUD
- Booking and cancellation
- Conflict detection
- Event management
- Event registration
- Notifications
- Usage and activity reports
- File export
- Runtime annotation and reflection diagnostics
- JDBC reporting
- Background monitoring thread

## Expected Outcome

The application demonstrates how Java language features can be combined into a modular real-world information system while maintaining separation between user interaction, business logic and persistence.
